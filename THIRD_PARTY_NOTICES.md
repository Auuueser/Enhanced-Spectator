## Generic Vorbis setup tables

Four generic codec setup packets (no game recordings) are selected from [Fmod5Sharp](https://github.com/SamboyCoding/Fmod5Sharp), commit `28951c6fb625522dcac4a129e28a53f33b6a3ba8`. The bounded local FSB-to-Ogg repacker follows the documented packet/block-size approach. No Fmod5Sharp runtime DLL is redistributed.
